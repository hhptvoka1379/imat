Every row in the dataset is a 60-cell pattern of correct / wrong / blank. You paint a pattern of sure / unsure / wrong / blank. A cost table scores how well the two agree — 0 when they match, ~6 when one of them clearly contradicts the other, cheap when you said unsure and the row says you answered either way. Cheapest row wins. Because unsure only costs half a point, guessing rarely hurts you; it just widens the field. Nothing is uploaded: the whole dataset lives in this tab and the search is a few typed-array passes over it.
